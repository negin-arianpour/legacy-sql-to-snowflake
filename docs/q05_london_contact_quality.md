# Q05: Contact data quality check for London customers

Source dialect: **tsql**  
Generated by: `claude-opus-5-5`

## Purpose
Checks the quality of contact details for customers based in London.

## Inputs
`customers`.

## Logic
1. Select customers whose city is London in any letter case.
2. Report the name length without trailing spaces, the position of `@` in the email, the email domain and whether a phone number is recorded.

## Output columns
| Column | Type | Description |
|---|---|---|
| customer_id | INTEGER | Customer key |
| name | VARCHAR | Name as stored (trailing spaces kept) |
| name_length | INTEGER | Length ignoring trailing spaces |
| at_position | INTEGER | Position of `@` (0 if absent, NULL if email is NULL) |
| email_domain | VARCHAR | Text after `@` |
| phone_status | VARCHAR | `missing` or `ok` |

## Conversion notes
Two silent behaviour changes are handled: `LEN` vs `LENGTH` on trailing spaces, and case insensitive collation on the city filter.

## Change log

* LEN ignores trailing spaces; replaced by LENGTH(RTRIM(...)).
* CHARINDEX and SUBSTRING exist in Snowflake with the same argument order.
* City filter wrapped in LOWER() to keep the case insensitive match ('London', 'LONDON').

## Original query

```sql
SELECT
    c.customer_id,
    c.name,
    LEN(c.name) AS name_length,
    CHARINDEX('@', c.email) AS at_position,
    SUBSTRING(c.email, CHARINDEX('@', c.email) + 1, LEN(c.email)) AS email_domain,
    CASE WHEN c.phone IS NULL THEN 'missing' ELSE 'ok' END AS phone_status
FROM customers c
WHERE c.city = 'london'
ORDER BY c.customer_id;
```

## Snowflake query

```sql
SELECT
    c.customer_id,
    c.name,
    LENGTH(RTRIM(c.name)) AS name_length,
    CHARINDEX('@', c.email) AS at_position,
    SUBSTRING(c.email, CHARINDEX('@', c.email) + 1, LENGTH(RTRIM(c.email))) AS email_domain,
    CASE WHEN c.phone IS NULL THEN 'missing' ELSE 'ok' END AS phone_status
FROM customers c
WHERE LOWER(c.city) = 'london'
ORDER BY c.customer_id;
```
