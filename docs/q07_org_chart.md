# Q07: Organisation chart with reporting paths

Source dialect: **oracle**  
Generated by: `claude-opus-5-5`

## Purpose
Produces the organisation chart: every employee with their depth, full reporting path and top manager.

## Inputs
`employees`.

## Logic
1. Start from employees with no manager (top of each tree).
2. Recursively add direct reports, increasing depth and extending the path.
3. Sort depth first so each manager is followed by their reports, siblings alphabetically.

## Output columns
| Column | Type | Description |
|---|---|---|
| emp_id | INTEGER | Employee key |
| emp_name | VARCHAR | Employee name |
| depth | INTEGER | 1 for top managers |
| reporting_path | VARCHAR | `/Top/.../Employee` |
| top_manager | VARCHAR | Root of the employee's tree |

## Conversion notes
Snowflake does support `CONNECT BY`, but not `ORDER SIBLINGS BY`, so a recursive CTE with path ordering is used for a portable and deterministic result.

## Change log

* CONNECT BY replaced by a recursive CTE (START WITH becomes the anchor member).
* LEVEL becomes a depth counter, SYS_CONNECT_BY_PATH an accumulated string, CONNECT_BY_ROOT a carried column.
* ORDER SIBLINGS BY emp_name (not supported by Snowflake) emulated by sorting on the accumulated path, which gives depth first order with siblings alphabetical.
* Caveat: path sorting can misorder siblings when one name is a prefix of another followed by a space; not the case in this data.

## Original query

```sql
SELECT emp_id,
       emp_name,
       LEVEL AS depth,
       SYS_CONNECT_BY_PATH(emp_name, '/') AS reporting_path,
       CONNECT_BY_ROOT emp_name AS top_manager
FROM employees
START WITH manager_id IS NULL
CONNECT BY PRIOR emp_id = manager_id
ORDER SIBLINGS BY emp_name;
```

## Snowflake query

```sql
WITH RECURSIVE org (emp_id, emp_name, depth, reporting_path, top_manager) AS (
    SELECT emp_id,
           emp_name,
           1,
           '/' || emp_name,
           emp_name
    FROM employees
    WHERE manager_id IS NULL
    UNION ALL
    SELECT e.emp_id,
           e.emp_name,
           o.depth + 1,
           o.reporting_path || '/' || e.emp_name,
           o.top_manager
    FROM employees e
    JOIN org o ON e.manager_id = o.emp_id
)
SELECT emp_id, emp_name, depth, reporting_path, top_manager
FROM org
ORDER BY reporting_path;
```
