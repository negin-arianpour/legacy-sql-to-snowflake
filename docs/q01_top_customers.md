# Q01: Top 5 customers by gross revenue

Source dialect: **tsql**  
Generated by: `claude-opus-5-5`

## Purpose
Lists the five customers who generated the most gross revenue from orders that were not cancelled.

## Inputs
`customers`, `orders`, `order_items`.

## Logic
1. Join each customer to their orders and order lines.
2. Exclude cancelled orders (case insensitive match, as in SQL Server).
3. Sum quantity times unit price per customer and count distinct orders.
4. Sort by revenue, highest first, and keep the top five.

## Output columns
| Column | Type | Description |
|---|---|---|
| customer_id | INTEGER | Customer key |
| customer_label | VARCHAR | Name plus city in brackets; NULL when city is unknown |
| contact_email | VARCHAR | Email, or `n/a` when missing |
| gross_revenue | NUMBER(38,2) | Sum of quantity x unit price |
| order_count | INTEGER | Number of distinct non cancelled orders |

## Conversion notes
Row limiting moves from `TOP` to `LIMIT`. Concatenation keeps NULL propagation, which matches T-SQL with `CONCAT_NULL_YIELDS_NULL ON` (the default). The status comparison is made case insensitive explicitly because Snowflake comparisons are case sensitive.

## Change log

* TOP 5 replaced by LIMIT 5 after ORDER BY.
* T-SQL + string concatenation replaced by ||; both return NULL when city is NULL, so the label stays NULL as in the source.
* ISNULL replaced by COALESCE.
* Status filter wrapped in UPPER() to keep SQL Server's case insensitive comparison.

## Original query

```sql
SELECT TOP 5
    c.customer_id,
    c.name + ' (' + c.city + ')' AS customer_label,
    ISNULL(c.email, 'n/a') AS contact_email,
    SUM(oi.quantity * oi.unit_price) AS gross_revenue,
    COUNT(DISTINCT o.order_id) AS order_count
FROM customers c
JOIN orders o ON o.customer_id = c.customer_id
JOIN order_items oi ON oi.order_id = o.order_id
WHERE o.status <> 'CANCELLED'
GROUP BY c.customer_id, c.name, c.city, c.email
ORDER BY gross_revenue DESC;
```

## Snowflake query

```sql
SELECT
    c.customer_id,
    c.name || ' (' || c.city || ')' AS customer_label,
    COALESCE(c.email, 'n/a') AS contact_email,
    SUM(oi.quantity * oi.unit_price) AS gross_revenue,
    COUNT(DISTINCT o.order_id) AS order_count
FROM customers c
JOIN orders o ON o.customer_id = c.customer_id
JOIN order_items oi ON oi.order_id = o.order_id
WHERE UPPER(o.status) <> 'CANCELLED'
GROUP BY c.customer_id, c.name, c.city, c.email
ORDER BY gross_revenue DESC
LIMIT 5;
```
