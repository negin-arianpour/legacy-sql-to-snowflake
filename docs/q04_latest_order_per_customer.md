# Q04: Most recent order for each customer

Source dialect: **tsql**  
Generated by: `claude-opus-5-5`

## Purpose
Returns each customer's most recent order.

## Inputs
`customers`, `orders`.

## Logic
1. Join customers to their orders.
2. Number each customer's orders from newest to oldest (order id breaks ties on the same date).
3. Keep row number 1. Customers without orders do not appear.

## Output columns
| Column | Type | Description |
|---|---|---|
| customer_id | INTEGER | Customer key |
| name | VARCHAR | Customer name |
| order_id | INTEGER | Latest order |
| order_date | DATE | Date of latest order |
| status | VARCHAR | Status of latest order |

## Conversion notes
`QUALIFY` is the idiomatic Snowflake replacement for a correlated `TOP 1`. If `OUTER APPLY` had been used, a `LEFT JOIN` would be required instead.

## Change log

* CROSS APPLY with TOP 1 rewritten as an inner join filtered with QUALIFY ROW_NUMBER() = 1.
* Inner join keeps CROSS APPLY behaviour: customers with no orders are excluded.
* Tie break on order_id DESC preserved.

## Original query

```sql
SELECT
    c.customer_id,
    c.name,
    lo.order_id,
    lo.order_date,
    lo.status
FROM customers c
CROSS APPLY (
    SELECT TOP 1 o.order_id, o.order_date, o.status
    FROM orders o
    WHERE o.customer_id = c.customer_id
    ORDER BY o.order_date DESC, o.order_id DESC
) lo
ORDER BY c.customer_id;
```

## Snowflake query

```sql
SELECT
    c.customer_id,
    c.name,
    o.order_id,
    o.order_date,
    o.status
FROM customers c
JOIN orders o ON o.customer_id = c.customer_id
QUALIFY ROW_NUMBER() OVER (
    PARTITION BY c.customer_id
    ORDER BY o.order_date DESC, o.order_id DESC
) = 1
ORDER BY c.customer_id;
```
