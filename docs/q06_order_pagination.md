# Q06: Second page (rows 6 to 10) of orders ranked by net value

Source dialect: **oracle**  
Generated by: `claude-opus-5-5`

## Purpose
Returns the second page (rows 6 to 10) of orders ranked by net value.

## Inputs
`orders`, `customers`, `order_items`.

## Logic
1. Compute each order's net value: line total less the order discount, rounded to 2 decimals.
2. Map status codes to labels (exact, case sensitive match as in Oracle).
3. Rank orders by net value descending, then order id, and return positions 6 to 10.

## Output columns
| Column | Type | Description |
|---|---|---|
| order_id | INTEGER | Order key |
| customer_name | VARCHAR | Customer name |
| order_month | VARCHAR | `YYYY-MM` |
| status_label | VARCHAR | Done, Waiting or Other |
| net_value | NUMBER | Net order value |
| rn | INTEGER | Position in the ranking |

## Conversion notes
Oracle needs a three level query because `ROWNUM` is assigned before `ORDER BY`. A window function does the same in one level.

## Change log

* The nested ROWNUM pagination pattern replaced by ROW_NUMBER() and a BETWEEN filter.
* Comma joins rewritten as explicit JOIN ... ON.
* DECODE, NVL, TO_CHAR and ROUND are supported natively by Snowflake and kept.

## Original query

```sql
SELECT order_id, customer_name, order_month, status_label, net_value, rn
FROM (
    SELECT a.*, ROWNUM rn
    FROM (
        SELECT o.order_id,
               c.name AS customer_name,
               TO_CHAR(o.order_date, 'YYYY-MM') AS order_month,
               DECODE(o.status, 'SHIPPED', 'Done', 'PENDING', 'Waiting', 'Other') AS status_label,
               ROUND(SUM(oi.quantity * oi.unit_price) * (1 - NVL(o.discount_pct, 0) / 100), 2) AS net_value
        FROM orders o, customers c, order_items oi
        WHERE o.customer_id = c.customer_id
          AND oi.order_id = o.order_id
        GROUP BY o.order_id, c.name, o.order_date, o.status, o.discount_pct
        ORDER BY net_value DESC, o.order_id
    ) a
    WHERE ROWNUM <= 10
)
WHERE rn > 5
ORDER BY rn;
```

## Snowflake query

```sql
SELECT order_id, customer_name, order_month, status_label, net_value, rn
FROM (
    SELECT o.order_id,
           c.name AS customer_name,
           TO_CHAR(o.order_date, 'YYYY-MM') AS order_month,
           DECODE(o.status, 'SHIPPED', 'Done', 'PENDING', 'Waiting', 'Other') AS status_label,
           ROUND(SUM(oi.quantity * oi.unit_price) * (1 - NVL(o.discount_pct, 0) / 100), 2) AS net_value,
           ROW_NUMBER() OVER (
               ORDER BY ROUND(SUM(oi.quantity * oi.unit_price) * (1 - NVL(o.discount_pct, 0) / 100), 2) DESC,
                        o.order_id
           ) AS rn
    FROM orders o
    JOIN customers c ON o.customer_id = c.customer_id
    JOIN order_items oi ON oi.order_id = o.order_id
    GROUP BY o.order_id, c.name, o.order_date, o.status, o.discount_pct
)
WHERE rn BETWEEN 6 AND 10
ORDER BY rn;
```
