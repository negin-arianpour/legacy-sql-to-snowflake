# Q08: Product sales ranked within category (including unsold products)

Source dialect: **oracle**  
Generated by: `claude-opus-5-5`

## Purpose
Ranks products by revenue within their category, including products that have never been sold.

## Inputs
`products`, `order_items`.

## Logic
1. Left join products to order lines so every product appears.
2. Total units and revenue per product (0 when never sold) and flag sales status.
3. Rank products within each category by revenue, highest first.

## Output columns
| Column | Type | Description |
|---|---|---|
| category | VARCHAR | Product category |
| product_name | VARCHAR | Product |
| units_sold | INTEGER | Units sold, 0 if none |
| revenue | NUMBER | Revenue, 0 if none |
| sales_status | VARCHAR | Active or Never sold |
| category_rank | INTEGER | Rank within category |

## Conversion notes
The `(+)` marker sits on the optional side (`order_items`), so the equivalent ANSI join is `products LEFT JOIN order_items`.

## Change log

* Oracle (+) outer join rewritten as LEFT JOIN so unsold products are kept.
* NVL, NVL2 and RANK() OVER are supported by Snowflake and kept unchanged.

## Original query

```sql
SELECT p.category,
       p.product_name,
       NVL(SUM(oi.quantity), 0) AS units_sold,
       NVL(SUM(oi.quantity * oi.unit_price), 0) AS revenue,
       NVL2(MAX(oi.order_id), 'Active', 'Never sold') AS sales_status,
       RANK() OVER (PARTITION BY p.category
                    ORDER BY NVL(SUM(oi.quantity * oi.unit_price), 0) DESC) AS category_rank
FROM products p, order_items oi
WHERE p.product_id = oi.product_id(+)
GROUP BY p.category, p.product_name
ORDER BY p.category, category_rank, p.product_name;
```

## Snowflake query

```sql
SELECT p.category,
       p.product_name,
       NVL(SUM(oi.quantity), 0) AS units_sold,
       NVL(SUM(oi.quantity * oi.unit_price), 0) AS revenue,
       NVL2(MAX(oi.order_id), 'Active', 'Never sold') AS sales_status,
       RANK() OVER (PARTITION BY p.category
                    ORDER BY NVL(SUM(oi.quantity * oi.unit_price), 0) DESC) AS category_rank
FROM products p
LEFT JOIN order_items oi ON p.product_id = oi.product_id
GROUP BY p.category, p.product_name
ORDER BY p.category, category_rank, p.product_name;
```
