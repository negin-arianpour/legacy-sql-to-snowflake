# Q03: Basket statistics per product category

Source dialect: **tsql**  
Generated by: `claude-opus-5-5`

## Purpose
Basket statistics for each product category: how many orders include the category and typical quantities and prices.

## Inputs
`order_items`, `products`.

## Logic
1. Join order lines to products to get the category.
2. Per category, count distinct orders, divide total units by that count, average line quantity and average unit price.
3. All three averages are whole numbers truncated toward zero, as SQL Server produced them.

## Output columns
| Column | Type | Description |
|---|---|---|
| category | VARCHAR | Product category |
| orders_with_category | INTEGER | Distinct orders containing the category |
| avg_units_per_order | INTEGER | Total units / orders, truncated |
| avg_line_quantity | INTEGER | Average quantity per line, truncated |
| avg_price_whole | INTEGER | Average unit price, truncated to a whole number |

## Conversion notes
This query looks portable but is not: three expressions rely on T-SQL integer semantics. Without `TRUNC` Snowflake would return 1.6 instead of 1, or round 188.66 up to 189.

## Change log

* SUM(int) / COUNT(...) is integer division in T-SQL; wrapped in TRUNC to keep the truncated result.
* AVG over an INTEGER column returns an integer in T-SQL; wrapped in TRUNC to match.
* CAST(... AS INT) truncates in T-SQL but rounds in Snowflake; TRUNC applied before the cast.

## Original query

```sql
SELECT
    p.category,
    COUNT(DISTINCT oi.order_id) AS orders_with_category,
    SUM(oi.quantity) / COUNT(DISTINCT oi.order_id) AS avg_units_per_order,
    AVG(oi.quantity) AS avg_line_quantity,
    CAST(AVG(oi.unit_price) AS INT) AS avg_price_whole
FROM order_items oi
JOIN products p ON p.product_id = oi.product_id
GROUP BY p.category
ORDER BY p.category;
```

## Snowflake query

```sql
SELECT
    p.category,
    COUNT(DISTINCT oi.order_id) AS orders_with_category,
    CAST(TRUNC(SUM(oi.quantity) / COUNT(DISTINCT oi.order_id)) AS INT) AS avg_units_per_order,
    CAST(TRUNC(AVG(oi.quantity)) AS INT) AS avg_line_quantity,
    CAST(TRUNC(AVG(oi.unit_price)) AS INT) AS avg_price_whole
FROM order_items oi
JOIN products p ON p.product_id = oi.product_id
GROUP BY p.category
ORDER BY p.category;
```
