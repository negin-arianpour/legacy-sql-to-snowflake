# Q02: Shipped orders per month, first half of 2025

Source dialect: **tsql**  
Generated by: `claude-opus-5-5`

## Purpose
Monthly summary of shipped orders for January to June 2025.

## Inputs
`orders`.

## Logic
1. Keep orders whose status is shipped (any letter case) and whose date falls in the six months starting 1 January 2025.
2. Group by calendar month (`YYYY-MM`).
3. Count orders, measure the days between the first and last order in the month, and total the discount percentages (NULL counted as 0).

## Output columns
| Column | Type | Description |
|---|---|---|
| order_month | VARCHAR | Month as `YYYY-MM` |
| orders_shipped | INTEGER | Shipped orders in the month |
| span_days | INTEGER | Days between first and last shipped order |
| total_discount_pct | INTEGER | Sum of discount percentages |

## Conversion notes
Style 120 of `CONVERT` produces `yyyy-mm-dd hh:mi:ss`; truncating to seven characters gives `YYYY-MM`, which `TO_CHAR` produces directly. The case insensitive status match is made explicit.

## Change log

* CONVERT(VARCHAR(7), date, 120) replaced by TO_CHAR(date, 'YYYY-MM').
* String literals cast explicitly to DATE for the range filter.
* DATEDIFF and DATEADD kept: Snowflake supports the same argument order.
* Status filter wrapped in UPPER() so values such as 'Shipped' still match, as under SQL Server collation.

## Original query

```sql
SELECT
    CONVERT(VARCHAR(7), o.order_date, 120) AS order_month,
    COUNT(*) AS orders_shipped,
    DATEDIFF(day, MIN(o.order_date), MAX(o.order_date)) AS span_days,
    SUM(ISNULL(o.discount_pct, 0)) AS total_discount_pct
FROM orders o
WHERE o.status = 'SHIPPED'
  AND o.order_date >= '2025-01-01'
  AND o.order_date < DATEADD(month, 6, '2025-01-01')
GROUP BY CONVERT(VARCHAR(7), o.order_date, 120)
ORDER BY order_month;
```

## Snowflake query

```sql
SELECT
    TO_CHAR(o.order_date, 'YYYY-MM') AS order_month,
    COUNT(*) AS orders_shipped,
    DATEDIFF(day, MIN(o.order_date), MAX(o.order_date)) AS span_days,
    SUM(COALESCE(o.discount_pct, 0)) AS total_discount_pct
FROM orders o
WHERE UPPER(o.status) = 'SHIPPED'
  AND o.order_date >= '2025-01-01'::DATE
  AND o.order_date < DATEADD(month, 6, '2025-01-01'::DATE)
GROUP BY TO_CHAR(o.order_date, 'YYYY-MM')
ORDER BY order_month;
```
